Fonts are self-hosted. License texts are adjacent.

TableBook Sans is the existing renamed derivative of Atkinson Hyperlegible Next
from the supplied product build. Both weights are unchanged here.

Porch Serif is a static instance made from the supplied Source Serif 4 variable
font, at weight 550 and optical size 32, for the website's display headings.
The internal family was renamed to respect the reserved Source name. The
original copyright is retained. CSS uses a local family alias. This reduces the
heading font from approximately 187 KB to approximately 32 KB. No external font
requests are needed. The original full variable file is not shipped.
